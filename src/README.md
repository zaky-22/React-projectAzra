## Fitur Utama
1. **Responsive Layout:** Tampilan otomatis menyesuaikan ukuran layar (1 kolom atau grid 2 kolom).
2. **Pencarian Entri (SearchBar):** Menyaring daftar catatan secara dinamis berdasarkan judul, tanggal, atau ringkasan.
3. **Form Tambah Entri (EntryForm):** Memungkinkan pengguna menambahkan catatan baru secara *real-time*.
4. **Fitur Like:** Menandai catatan favorit dengan ikon hati (*like*) tanpa perlu me-*reload* aplikasi.
5. **Mood-Based Border:** Kartu catatan memiliki warna *border* dinamis yang berubah sesuai jenis *mood*.
6. **Modal Detail:** Menampilkan isi catatan secara lengkap saat kartu ditekan.
